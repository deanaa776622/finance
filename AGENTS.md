# finance — agent notes

This repo currently holds a **web** prototype. The product direction is a native **iOS** long-term asset recording app.

Mandatory product principles live in the personal skill `ios-app` → `product-principles.md`. Summary:

- Purpose: long-term asset investing records — trend, allocation balance, whether to adjust.
- Not a day-trading or daily P&L anxiety tool. Do not center today’s stock moves.
- UI: calm, minimal, Apple HIG.
- Prefer long time ranges; quiet rebalance cues over alarmist red/green flash.
- Code: clear file layout, short files (~150 lines), no duplicated shared logic (`ios-app` → `code-structure.md`).

When building iOS, follow skill `ios-app` (Ponytail + product principles + code structure). Use this web app only as conceptual reference.
