# Calm Ledger — UI redesign mockups

Static Stitch-style design package. **No Swift / app code changes.**

## How these were made

1. Read product principles (long-term calm, allocation over daily P&L).
2. Followed `stitch-skills` `generate-design` prompt pipeline + `taste-design` anti-generic rules.
3. Stitch MCP was not available in this environment, so screens were authored as local mobile HTML and screenshot-rendered (same deliverable shape as Stitch: HTML + PNG).

## Screens

| Screen | Intent |
| --- | --- |
| `designs/01-home` | Full-bleed status: 平衡 + soft mist orbs |
| `designs/02-assets` | Docked hero + 5y trend + quiet holdings list |
| `designs/03-savings` | Years-to-goal hero + 目標 / 計畫 / 現狀 |
